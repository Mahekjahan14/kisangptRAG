# Chickpea Production

Chickpea needs well-drained soil and cool dry weather. Seed treatment helps manage wilt and root rot. Avoid excessive irrigation because waterlogging damages roots. Helicoverpa pod borer should be monitored with pheromone traps and economic threshold-based control.
