# Wheat Weed Management

Major wheat weeds include Phalaris minor, wild oat, bathua and other broadleaf weeds. Use clean seed, timely sowing, crop rotation, stale seedbed and recommended herbicides. Repeated use of the same herbicide can create resistance, so rotate modes of action.
