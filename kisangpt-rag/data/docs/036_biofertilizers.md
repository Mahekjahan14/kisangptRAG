# Biofertilizers

Biofertilizers such as Rhizobium, Azotobacter, Azospirillum and phosphate solubilizing bacteria improve nutrient availability. Use crop-specific inoculants, keep away from heat and sunlight, and apply before expiry date. Chemical seed treatment compatibility should be checked.
