# Onion Production and Storage

Onion needs good nursery management, proper spacing, balanced fertilizer and irrigation. Stop irrigation before harvest to improve curing. Cure bulbs in shade with good ventilation and store only well-dried, disease-free bulbs to reduce rotting.
